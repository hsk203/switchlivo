## 📌 About

This is the official marketing website for **Switchlivo**, a smart-home / smart-hotel / smart-lighting OEM & ODM manufacturer.

- Complete smart-home ecosystem (gateway, switches, sensors, lighting, and more)
- Customizable OEM / ODM manufacturing
- Integrated R&D, production, and sales

The site is built with **Astro + TailwindCSS** and shipped as a static site on **Cloudflare Pages**.

## 🛠️ Tech Stack

- [Astro](https://astro.build) — static site generator
- [TailwindCSS](https://tailwindcss.com) — styling
- TypeScript

## 🚀 Local Development

Prerequisites: **Node.js 22** (LTS recommended).

```bash
# install dependencies
npm install

# start the local dev server
npm run dev
```

## 🏗️ Production Build

```bash
npm run build
```

The built site is emitted to the `dist/` directory.

## ☁️ Deployment (Cloudflare Pages)

- Build command: `npm run build`
- Output directory: `dist`
- Node version: `22`
